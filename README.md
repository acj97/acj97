I build interfaces for a living: fintech dashboards, legal-tech portals, government
data platforms, and, most recently, a fair amount of Web3. I focus on component-based
architecture, design systems, and frontend performance across React and Next.js
applications.

- 🛠️ **Daily drivers:** React, Next.js, TypeScript, Tailwind CSS, Framer Motion
- 🧠 **Also experienced with:** Vue, state management (Redux/Zustand/Vuex), data
  visualization, and Web3 integration tooling (Ethers.js, Wagmi, WalletConnect)
- 🏗️ Recently shipped a 9-chain bridge UI, a liquid-staking dashboard, a
  configurable multi-signature wallet, and an interactive CLMM liquidity chart for a
  DEX trading platform
- 🤖 Experienced with AI-assisted development workflows, including Claude Code

### Currently

- 💼 Open to new frontend/full-stack opportunities
- 🌱 Exploring AI development and automation
- 🎥 Building a project that generates YouTube videos end-to-end using AI
